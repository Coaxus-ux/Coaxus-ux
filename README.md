## 🧠 Engineering philosophy

| Principle | Practice |
|---|---|
| **Architecture first** | SOLID, Hexagonal Architecture, DDD |
| **Code that survives time** | Readability over cleverness |
| **Systems thinking** | Scalability, observability, fault tolerance |
| **UX matters** | Engineering decisions should serve users |

I care more about the decisions made before writing code than the code itself. Structure, boundaries, and intent — get those right, and everything else follows.
